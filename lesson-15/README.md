# 15강 콘솔 주문 프로그램 완성하기

Java 21, Gradle Wrapper 9.2.1, JUnit 6.0.3을 사용합니다. IntelliJ에서 `Main.main`을 실행하거나 이 폴더에서 `./gradlew -q --console=plain run`을 실행하세요. 메뉴는 0으로 종료합니다. 테스트 명령은 `./gradlew test`입니다.

2번 메뉴에서 P001 수량 2와 P002 수량 1을 담고, 6번으로 주문을 확정합니다. 상품 금액은 75,000원, 할인은 5,000원, 배송비는 0원, 최종 금액은 70,000원입니다. 8번으로 요약을 저장한 뒤 프로그램을 다시 실행해 9번으로 읽습니다. 저장 경로는 같은 작업 디렉터리의 `data/latest-order.txt`입니다.

공개 코드는 기본 메뉴가 완성된 프로젝트 하나입니다. 취소 메뉴를 연결하는 추가 과제와 해답은 로컬 강의 자료에 있습니다. 파일에는 요약 문자열을 저장하며, 주문 객체를 복원하려면 별도 구현이 필요합니다.
