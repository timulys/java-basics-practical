# 2강 · 강의를 따라 작성할 시작 코드

IntelliJ의 **File → Open**에서 이 폴더를 열고 프로젝트 SDK와 Gradle JVM을 Java 21로 맞춥니다. Gradle 동기화가 끝나면 [Main.java](src/main/java/study/javaorder/Main.java)의 `main`을 실행합니다.

터미널에서는 이 폴더 안에서 실행합니다.

```sh
./gradlew -q run
```

Windows 명령 프롬프트에서는 `gradlew.bat -q run`, PowerShell에서는 `.\gradlew.bat -q run`을 사용합니다.
