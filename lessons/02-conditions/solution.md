# 2강 과제 풀이

배송비 조건의 기준만 70,000원으로 바꿉니다. 할인 조건의 50,000원과 할인액 5,000원은 유지합니다.

```java
long discount = 0L;
if (subtotal >= 50_000L) {
    discount = 5_000L;
}

long shippingFee = 3_000L;
if (subtotal >= 70_000L) {
    shippingFee = 0L;
} else {
    shippingFee = 3_000L;
}

long total = subtotal - discount + shippingFee;
```

상품 금액이 60,000원이면 할인 조건은 참이고 무료배송 조건은 거짓입니다. 따라서 60,000 − 5,000 + 3,000 = 58,000원입니다. 70,000원이면 두 조건이 모두 참이므로 70,000 − 5,000 + 0 = 65,000원입니다. 69,999원은 무료배송 기준보다 작아서 배송비 3,000원이 붙고 최종 금액은 67,999원입니다.

해답 프로젝트는 `code/solution`입니다. 기본 상품 단가 30,000원·수량 2개를 유지하므로 그대로 실행하면 최종 금액 58,000원이 나옵니다. 70,000원 입력은 `code/checkpoints/22-exercise-70000/Main.java`로 확인합니다.

다음 강의의 기본 코드에는 할인과 무료배송 모두 50,000원 기준을 사용합니다. 과제 해답과 기본 완성 코드를 구분해 보관합니다.
