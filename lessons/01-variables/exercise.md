# 1강 연습 문제

code/exercise 프로젝트에서 상품 금액에 배송비를 더해보세요. 기본 상품은 단가 30000원의 키보드이며 수량은 2입니다.

배송비 3000원을 담을 long 변수를 만들고, 상품 금액과 배송비를 더한 최종 금액도 long 변수에 저장합니다. 상품 금액·배송비·최종 금액을 구분해 출력합니다.

| 항목 | 기대값 |
|---|---|
| 상품 금액 | 60000원 |
| 배송비 | 3000원 |
| 최종 금액 | 63000원 |

수량을 3으로 바꾼 뒤 다시 실행해보세요. 상품 금액은 90000원, 배송비는 같은 3000원, 최종 금액은 93000원이어야 합니다. 계산을 마쳤다면 수량은 기본값 2로 돌려놓습니다.

변수를 처음 만들 때 자료형을 적었는지, 최종 금액을 문자열로 연결하기 전에 숫자 덧셈을 했는지 확인해보세요.
